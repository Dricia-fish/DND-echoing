# DND小队匿名论坛（Supabase共享版）

当前版本支持多人共享帖子（云端存储），并保留：

- DND 主题 UI
- 自选身份 + 自定义身份
- 发帖自动 d20
- 大成功/大失败特效
- 点赞、回复、删除
- 排序、分页、每日热度榜
- 实时同步（别人发帖你会自动刷新）
- 仅发帖本人可删自己的帖（其他人无权删除）

## 1. 创建 Supabase 项目

1. 打开 https://supabase.com
2. 新建项目
3. 在 Project Settings -> API 中获取：
   - Project URL
   - anon public key

## 2. 建表（SQL Editor 执行）

```sql
create table if not exists posts (
  id bigint generated by default as identity primary key,
  title text not null,
  content text not null,
  alias text not null,
  likes integer not null default 0,
  dice_result integer,
  owner_id uuid not null,
  created_at timestamptz not null default now()
);

create table if not exists replies (
  id bigint generated by default as identity primary key,
  post_id bigint not null references posts(id) on delete cascade,
  content text not null,
  alias text not null,
  created_at timestamptz not null default now()
);

alter table posts add column if not exists owner_id uuid;
```

## 3. 开启 RLS 并添加策略（匿名登录 + 所有人可读，删帖仅作者）

```sql
alter table posts enable row level security;
alter table replies enable row level security;

drop policy if exists "posts_public_read" on posts;
drop policy if exists "posts_public_insert" on posts;
drop policy if exists "posts_public_update" on posts;
drop policy if exists "posts_public_delete" on posts;
drop policy if exists "replies_public_read" on replies;
drop policy if exists "replies_public_insert" on replies;
drop policy if exists "replies_public_delete" on replies;

create policy "posts_read_all" on posts
for select to authenticated using (true);

create policy "posts_insert_owner" on posts
for insert to authenticated
with check (owner_id = auth.uid());

create policy "posts_update_all" on posts
for update to authenticated using (true);

create policy "posts_delete_own" on posts
for delete to authenticated
using (owner_id = auth.uid());

create policy "replies_read_all" on replies
for select to authenticated using (true);

create policy "replies_insert_all" on replies
for insert to authenticated with check (true);

create policy "replies_delete_all" on replies
for delete to authenticated using (true);
```

> 说明：前端已自动执行匿名登录（anonymous auth），每台设备会有独立 `auth.uid()`。

## 4. Supabase Auth 打开匿名登录

1. Authentication -> Providers
2. 打开 Anonymous Sign-Ins
3. 保存

## 5. 在网页中填写 Supabase 配置

1. 打开网页
2. 在“云端连接设置（仅首次）”里填 URL 和 anon key
3. 点击“保存并连接云端”

配置会存到浏览器本地，下次自动连接。

## 6. 权限效果

- 所有人都能看帖、回帖、点赞
- 只有发帖人自己的设备账号（owner_id = auth.uid）能删除该帖
- 其他人看不到删除按钮，就算手动调接口也会被数据库拒绝
